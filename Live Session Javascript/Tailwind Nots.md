### **Introduction to Tailwind**

-Tailwind CSS is opensource CSS framework, a utility-first CSS framework with predefined classes that you can use to build and design web pages directly in your markup language.



-Utility-first approach in CSS is a Methodology where you style your webpage by applying small, focused utility classes directly to your HTML elements



### **Benefits of Using Tailwind CSS**

-Rapid Development

-Consistency

-Flexibility and Customization

-Readability and Predictability

-Responsive Design Made Easy

-Reduce file size with JIT mode

-Maintenance Efficienecy

-Focus on Design rather than structure



### **Limitations of Tailwind CSS**

-Learn Curve

-Messy HTML

-Limited Customization

-Not fancy out-of-box

-No JavaScript

-Lots to Remember

-style consistency pressure.
