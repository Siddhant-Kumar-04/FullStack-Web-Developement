##Event Driven Programming
To understant Event Driven Programming, we needs ro understand concept of event.
Events are some action or interaction done by an external agent(may be the user). on our application. For Example clicking a button is an event, scrolling is an event, moving the mouse is an event, pressing a button on keyboard is an event and so on.
So when we click a button an event is triggerd.

So react on these action, we can write logics which will only execute when these actions are triggered. And the programming paradigm where the logic/code runs as a reaction /response to these events is called as event driven programming.

##<element>.addEventListener

This method 'addEventListener'  is present on almost all of the HTML elements. We can select an HTML elements first and then call this 'addEventListener' function on that element.It takes two arguments:

1)Name of the event-example: click,dbclick,mouseover,scroll etc.
2)callback function which will be executed once the event is triggerd


```JS
const submitBtn1 = document.getElementById('clickMeButton');
submitBtn1.addEventListener('click', ()=> {
    console.log('Button Clicked');
})
```

This callback method will not be automaticlly called. it will be only called when click event happens on the submitbtn alltogether.
The addEventListener callback has a parameter called as the event object.This event object has a lot of details about the event triggered,like on which element this was triggered, what event got triggered and so on.

To get acess of the element on which the event was fired we can use the event.target property


##preventDefaut
Every event object passed in the event listener callback has a preventDefault method. which stops the dafault exection behavior of the event.
For Example: a click event on a submit button inside a form, submits the form and refreshes the page. this is the default behavior. we can avoid it by using event.preventDefault
